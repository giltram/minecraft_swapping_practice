# Layout customization

O → Edit item layout lists the available layouts and marks the current training
selection. Click a layout name to select and persist it immediately. The adjacent
Edit button opens that exact file for editing without changing the selection.
There is no separate Profile control in options.

Edit → slot opens the multi-select item catalogue. Click to select/deselect items; selected icons/counts appear above and
catalogue choices are marked green. Click a selected icon for its labelled left-aligned quantity and adjacent Delete.
No selections after editing means EMPTY. Done returns to the overview; Save layout
alone writes. One and many allowed items have the same presentation.

The overview has name, hotbar/offhand, Reset/Save/Cancel. Exchange positions and
its coordinator state were removed from the current GUI. The compatible
saveSlotOrder backend remains tested; its historical screen is not an entry.
Advanced rules/NBT remain a secondary picker action, preserving complete legacy
profiles and nullable defaults. ProfileRepository owns all file I/O/atomic backup/
conflict checking. Server START still reloads/freezes independently.
