# Hotbar Swap Trainer

A small Fabric mod for Minecraft Java 1.16.1. Practice moving items between your hotbar and offhand without opening your inventory GUI. Designed specifically for Minecraft speedrunning.

Enter the automatically managed practice arena from the main menu. Ordinary worlds still require an explicit disposable-test marker.

Both inventory modes support Stationary, Moving and owned-arena Parkour. Parkour
pairs one inventory task with a basic checkpoint course; finish both to end the
run. [M3-C rules and verification](docs/m3-c-parkour.md) distinguish programmatic
checks from the still-pending human route/physical-input acceptance.
